# WASEEM ABBAS — Digital Marketer & Developer Portfolio

A high-performance 3D motion portfolio website engineered with WebGL Three.js, kinetic physics, and editorial typography, based on Dribbble inspiration.

## 🚀 Features
- **Interactive 3D WebGL Torus Sculpture:** Real-time mouse parallax, dual-tone chromatic sheen, and dynamic lighting.
- **Cinema Reel Mode:** Seamless synchronized high-definition animation reel.
- **3 Dynamic Themes:** Midnight Navy, Cyber Violet, and Monochrome Crimson.
- **Pillars of Expertise:** Performance Marketing (Meta & Google Ads), Full-Stack Development, Generative UI, and Technical SEO/CRO.
- **Live Info Personalizer:** In-browser customizable drawer with local storage persistence.
- **Responsive & Accessible:** Fully optimized across Desktop, Tablet, and Mobile.

## 🛠️ Tech Stack
- HTML5 / CSS3 (Custom Properties & Glassmorphism)
- Vanilla JavaScript & Three.js (WebGL)
- Font Awesome & Google Fonts (Cormorant Garamond, Cinzel, Plus Jakarta Sans, Space Mono)

## 📦 Deployment
Deployable with a single command to Vercel, Netlify, or GitHub Pages.
